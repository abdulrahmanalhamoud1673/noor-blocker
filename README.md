# نور — قفل الصلاة (تطبيق أندرويد)

هذا هو **الحظر الحقيقي**: إذا فتحت إنستغرام أو تيك توك وقت الصلاة، يرجّعك فوراً ولا يفتح حتى تصلّي.

> ⚠️ **لم أستطع تجربة هذا التطبيق على جهاز حقيقي**، لأن أدوات بناء أندرويد غير منصّبة على كمبيوترك. الكود مكتوب بعناية، والبناء يتم على GitHub. إذا ظهر أي خطأ أثناء البناء أو التشغيل، أرسله لي وأصلحه.

---

## كيف يشتغل؟

أندرويد يمنع أي تطبيق من إغلاق تطبيق آخر — إلا عبر بوابة واحدة اسمها **خدمة إمكانية الوصول** (Accessibility Service). هذه الخدمة تُعلم التطبيق باسم التطبيق الذي فُتح للتو.

فالمنطق:

1. تفتح إنستغرام
2. النظام يخبر خدمة نور: «فُتح `com.instagram.android`»
3. نور تسأل نفسها: هل هذا ضمن قائمتك؟ وهل الآن وقت صلاة؟
4. إذا نعم → تفتح شاشة قفل فوقه فوراً
5. الشاشة لا تُغلق إلا بزر **«صلّيت»** أو بانتهاء المدة

**الخصوصية:** الخدمة مضبوطة على `canRetrieveWindowContent="false"` — أي أنها **لا تستطيع** قراءة محتوى شاشتك، ولا كلمات السر، ولا الرسائل. تعرف فقط اسم التطبيق المفتوح. هذا مكتوب في ملف `accessibility_service_config.xml` ويمكنك التحقق منه.

## كيف أحصل على ملف APK؟

### الطريقة السهلة — GitHub يبنيه لك مجاناً

هذه خمس خطوات، مرة واحدة فقط:

**١. أنشئ حساب GitHub** (إذا ما عندك) من [github.com](https://github.com)

**٢. سجّل الدخول من الكمبيوتر.** افتح موجّه الأوامر في مجلد `noor-blocker` ونفّذ:

```bash
gh auth login
```

اختر GitHub.com ← HTTPS ← Login with a web browser، وانسخ الرمز الذي يظهر.

**٣. ارفع المشروع:**

```bash
git init && git add . && git commit -m "نور - قفل الصلاة"
```

ثم:

```bash
gh repo create noor-blocker --private --source=. --push
```

**٤. انتظر البناء.** افتح المستودع على GitHub ← تبويب **Actions**. سترى «بناء تطبيق نور» يعمل. يستغرق ٣–٥ دقائق أول مرة.

**٥. نزّل الملف.** اضغط على البناء المكتمل ← في الأسفل قسم **Artifacts** ← نزّل `noor-blocker-apk`. بداخله ملف `app-debug.apk`.

انقل الملف لهاتفك وثبّته.

### إذا فضّلت Android Studio

نزّل [Android Studio](https://developer.android.com/studio)، افتح مجلد `noor-blocker`، واضغط **Run**. حجم التنزيل حوالي ١ جيجا.

## التثبيت على الهاتف

1. انقل ملف `app-debug.apk` للهاتف (كيبل أو واتساب لنفسك)
2. افتحه — سيقول أندرويد «تثبيت من مصدر غير معروف»
3. اضغط **الإعدادات** واسمح للتطبيق الذي تثبّت منه
4. ارجع واضغط **تثبيت**

هذا طبيعي تماماً لأي تطبيق خارج متجر بلاي.

## الاستخدام — ثلاث خطوات

بعد فتح التطبيق:

**١) فعّل الخدمة**
اضغط «افتح إعدادات إمكانية الوصول» ← ابحث عن **نور — قفل الصلاة** ← فعّله.

قد يحذّرك أندرويد بأن الخدمة «قد تقرأ شاشتك» — هذه رسالة عامة يعرضها النظام لكل خدمات إمكانية الوصول. تطبيقنا معطّل عنده قراءة المحتوى كما شرحنا فوق.

**٢) اضبط مدة القفل**
من ٥ إلى ٣٠ دقيقة. الافتراضي ١٥.

**٣) اختر التطبيقات**
علّم على إنستغرام، تيك توك، يوتيوب، أو أي شيء يشتّتك، ثم اضغط **احفظ الاختيار**.

خلص. جرّب بأن تفتح إنستغرام وقت الصلاة.

## أسئلة متوقعة

**هل يقفل الهاتف كله؟**
لا. الهاتف يعمل عادي — الاتصالات والرسائل والكاميرا. فقط التطبيقات التي اخترتها تُمنع.

**كيف أخرج إذا احتجت طارئاً؟**
اضغط «صلّيت» — لكن اضغطه فقط بعد أن تصلّي فعلاً، فالتطبيق أداة تساعدك على نفسك.

**هل يستهلك بطارية؟**
لا يُذكر. الخدمة لا تعمل باستمرار — النظام ينبّهها فقط عند فتح تطبيق.

**من أين يعرف أوقات الصلاة؟**
يحسبها فلكياً داخل الهاتف بدون إنترنت — نفس معادلات تطبيق الويب. الافتراضي عمّان بزاوية ١٨ درجة (دائرة الإفتاء الأردنية).

**كيف أغيّر المدينة؟**
حالياً مضبوط على عمّان. قل لي مدينتك وأضيف قائمة اختيار.
