# نور — أذكار وقرآن (تطبيق أندرويد)

تطبيق واحد يفتح على **أذكار الصباح والمساء**، و**القرآن الكريم**، و**أوقات الصلاة** مع تنبيه الأذان في وقته — حتى لو كان الهاتف نائماً والتطبيق مغلقاً.

ومعها **حلقة ذكر**: رابط تفتحه لأهل البيت، يسبّح كلٌّ على هاتفه ويرى عدّاد الباقين.

---

## التنزيل

**<https://github.com/abdulrahmanalhamoud1673/noor-blocker/releases/latest>**

نزّل ملف `noor-v17.apk` من صفحة الإصدار وثبّته. التوقيع ثابت منذ v16.0، فالتحديثات تُثبَّت فوق بعضها بلا حذف.

---

## الأذونات — تسعة، كلّها عاديّة

| الإذن | لماذا |
|---|---|
| `INTERNET` | لعرض صفحة الأذكار والقرآن |
| `POST_NOTIFICATIONS` | لتنبيه الأذان |
| `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` | ليأتي التنبيه في دقيقته لا بعدها |
| `RECEIVE_BOOT_COMPLETED` | لإعادة جدولة الأذان بعد إعادة تشغيل الهاتف |
| `FOREGROUND_SERVICE` + `MEDIA_PLAYBACK` + `WAKE_LOCK` | ليكمل الأذان دقيقتيه ونصف بلا قطع |
| `VIBRATE` | اهتزاز مع التنبيه |

لا قائمة تطبيقاتك، ولا مايكروفون، ولا كاميرا، ولا موقع.

---

## ما كان قبلها ولماذا حُذف

كان التطبيق يحظر تطبيقات التواصل وقت الصلاة عبر **خدمة إمكانية الوصول** و**صلاحية مدير الجهاز**. وهما أكثر بابين يُرفض عليهما تطبيق في جوجل بلاي: الأولى لا تُمنح إلا لأدوات ذوي الاحتياجات، والثانية تُفحص بشدّة. فحُذف الحظر كلّه — ومعه شاشة القفل وتحدّي الاستغفار والنقاط وسجلّ الأحداث — ليصل التطبيق إلى الناس.
